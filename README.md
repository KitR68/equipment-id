# Equipment ID

**AI-powered equipment nameplate identification.** Upload a photograph of an
industrial equipment dataplate and the app will identify the manufacturer,
model number, serial number, and decoded manufacture date — learning new
manufacturer serial-number formats as it goes.

## Stack

- React 19 + Vite + TypeScript
- Tailwind CSS 4 + shadcn/ui
- OpenAI Chat Completions API (vision-capable model, called directly from
  the browser)
- Static-only — deployable to **Azure Static Web Apps** with no backend.

## How it works

1. The user uploads a JPG/PNG of an equipment nameplate.
2. The image is sent to OpenAI's vision model, which returns structured
   JSON: manufacturer, model number, serial number, any printed date, and
   the raw OCR text.
3. The app checks `localStorage` for a previously learned serial-number
   format for that manufacturer.
   - **Hit.** The known format is fed back to the model and the serial is
     decoded deterministically.
   - **Miss.** The model is asked to research the manufacturer's
     published serial-number conventions. The format it returns is then
     persisted to `localStorage` for next time.
4. The four results — Manufacturer, Model, Serial, Manufacture Date — are
   displayed in stamped dataplate-style cards, each with a confidence
   chip and (for the date) the determination explaining how it was
   derived.

The knowledge base is browser-local. There is no server, no shared
database, and no key stored anywhere except the user's browser.

## Configuration

Open the **Settings** dialog (top-right) and paste your OpenAI API key.
The default model is `gpt-4o`. Any vision-capable chat model works
(`gpt-4o`, `gpt-4o-mini`, `gpt-4-turbo`, …).

The key is kept in `localStorage` under `equipment-id:settings:v1` and is
sent only to `https://api.openai.com/v1/chat/completions` from the user's
device.

## Local development

```bash
pnpm install
pnpm dev      # http://localhost:3000
```

## Production build

```bash
pnpm build
```

The build output is written to `dist/` (a postbuild step flattens Vite's
`dist/public` and copies `staticwebapp.config.json` in).

## Deploying to Azure Static Web Apps

1. Connect this repository to an Azure Static Web App.
2. Set the build configuration to:
   - **App location:** `/`
   - **Output location:** `dist`
   - **Build command:** `pnpm install && pnpm build` (or use the default
     workflow generated by Azure).
3. After deployment, open the site and add your OpenAI API key in
   Settings.

`staticwebapp.config.json` ships SPA fallback to `index.html`, sane cache
headers for hashed assets, and basic security headers.
